# DayCare — Hospital Website (Frontend)

DayCare is a frontend-only hospital website built using HTML and CSS. It includes a homepage, an About Us page, a services overview with doctor profiles, a photo gallery with patient testimonials, and an appointment booking form. This project was built as a first-year HNDIT assignment to practice structuring a multi-page website and styling it with custom CSS — no frameworks, no JavaScript, just fundamentals.

## Pages

- **Home** — hero section with a welcome message and call-to-action
- **About** — hospital description and mission
- **Services** — overview of services offered (Laboratory Test, Health Check, General Dentistry) and featured doctors
- **Gallery** — photo gallery and patient testimonials
- **Book Now** — appointment booking form (first name, last name, address, phone number, appointment date)

## Built with

- HTML5
- CSS3 (custom styling, flexbox, grid, hover animations)
- RemixIcon and Font Awesome for icons


## Notes

This is a frontend-only project — the booking form is styled and validated in the browser, but does not connect to a backend or database.
